x-ui · 组件介绍

为你的应用，接入多维表格

x-ui 是面向 Vue 3 应用的前端组件库。多维表格将字段编辑、单元格选择与记录组织组合在一起，让开发者把精力放在业务数据与流程上。

体验多维表格

不同信息，用合适的字段表达

从项目事项到预算、排期与完成度，字段类型决定信息如何展示和编辑。字段配置支持描述、默认值和必填设置，数值与日期可按各自类型调整格式。

文本
事项、负责人和多行交付说明。
数字
交付件数等数值，可设置小数位与范围。
货币
预算与调整金额，支持币种、小数位和负数。
进度
用进度条与百分比呈现完成度。
日期
交付日期、评审时间，可配置显示格式。
单选与多选
用状态和标签组织选项，支持多项选择。
布尔
用勾选表达确认、完成等两种状态。

从一个单元格，到一片选区

双击单元格编辑，框选多个单元格进行复制、粘贴或清除。固定首列后，横向查看更多字段时仍能辨认当前事项；列宽和行高可以按内容调整。

让明细与汇总一起工作

通过筛选和排序定位记录，按字段分组查看业务进展。数值列支持求和等统计，分组汇总帮助你从具体事项看到整体情况。

交互交给组件，数据接入你的业务

组件提供表格界面、编辑与选择交互；应用负责接入数据读取、写入和业务规则。界面支持黑色、蓝色强调色与明暗主题，可融入现有应用。

首页展示的是可操作的“品牌焕新计划”示例。预算、进度、渠道和评审时间均使用实际字段渲染；示例修改保存在本次页面会话中，刷新或离开后返回首页会重新初始化。
